# assets/

**这个目录里的素材不进版本控制。**

视频、动图属于使用者自己的资产（也涉及版权与 AI 生成内容标识问题），
因此 `.gitignore` 排除了本目录下的所有内容，仓库里只保留这一份说明。

## 你可以把素材放在这里

推荐放法是把素材放在本目录，然后让 `cpp/wallpaper.txt` 用相对路径引用它：

```
..\assets\my_loop.mp4
```

这样整个仓库文件夹可以直接拷到别处或换台机器，路径依然有效
（配置文件里的相对路径是相对可执行文件所在目录解析的）。

## 支持的格式

| 类型 | 扩展名 |
| --- | --- |
| 视频（D3D11 + DXVA 硬解） | `.mp4` `.mov` `.avi` `.wmv` `.mkv` `.webm` `.m4v` |
| 动图 / 静态图（GDI+） | `.gif` 等 GDI+ 可解码格式 |

## 选素材的建议

- 尺寸不要超过屏幕分辨率：播放器按 **cover** 缩放，超出屏幕的部分会被裁掉，纯属浪费解码开销。
- 想做无缝循环，素材本身最好是首尾相接的循环片段（10 秒左右的短循环最省资源）。
- 使用 AI 生成的视频时，请保留容器内的 `ContentProducer` / 数字签名等隐式标识，不要剥离。
